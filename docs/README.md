# StayPookie — Project Documentation

The planning brain of the project: code tells you *how* things work now; these
docs tell you *what*, *why*, and *what's left*.

> Keep these honest — fix a doc in the same change as the code it describes.

## Using it

- **Starting work?** Check [05-todo.md](05-todo.md) + [03-roadmap.md](03-roadmap.md), then [04-conventions.md](04-conventions.md).
- **Finished something?** Tick it off in the same PR.
- **Made a non-obvious call?** One line in [06-decisions.md](06-decisions.md).
- **Target changed?** Update [01-vision.md](01-vision.md).
